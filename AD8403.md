# Digitales Potentiometer AD8403 – EAuto BMS
 
Für die Anzeige des Ladestandes wird die Tankanzeige des Kombiinstrumentes verwendet.
Dafür ist am Batteriemanagement-System ein digitales Potentiometer vom Typ AD8403
angebracht. Dieses stellt einen Widerstand ein, über den die Anzeige des Kombiinstruments
verändert werden kann.
 
Programmiert werden kann das Potentiometer über eine SPI-Schnittstelle. Diese ist im
8-Bit Modus konfiguriert. Dabei werden zwei Byte übertragen und an den IC übergeben:
einmal die Adresse im ersten Byte und zum zweiten die Daten im zweiten Byte. Da nur die
letzten zehn Bit im Register übernommen werden, werden die ersten sechs Bit vom AD8403
ignoriert und nur als Dummy-Bits mit 0 übertragen.
 
Die Clock-Polarität ist als Low und die Clock-Phase mit First Edge definiert. Dies dient
dazu, die Daten korrekt zu übertragen. Aktuell wird der Takt noch durch 128 geteilt. Dies
wird im weiteren Verlauf der Programmierung jedoch noch geändert.
 
Zudem ist die SPI-Schnittstelle als Master Only Transmit definiert. Damit wird der
MISO-Eingang am STM32 nicht benötigt und kann für andere Funktionen verwendet werden.

## Widerstandswerte
 
Die Potentiometer können in einem Wertebereich von 0 bis 255 dynamisch verändert werden.
Dies entspricht einem Widerstandswert von 0 Ω bis 1 kΩ.
 
| Registerwert | Widerstand |
|:------------:|:----------:|
| 0            | 0 Ω        |
| 128          | ~500 Ω     |
| 255          | 1 kΩ       |
 
## Funktionen zur Programmierung
 
Der IC stellt mehrere Funktionen für die Programmierung zur Verfügung.
 
| Funktion                        | Beschreibung                                                                  |
|:--------------------------------|:------------------------------------------------------------------------------|
| Initialisierung                 | IC initialisieren und SPI-Kommunikation starten                               |
| Einzelnes Potentiometer setzen  | Jedes der vier Potentiometer kann einzeln über seine Adresse eingestellt werden |
| Alle Potentiometer ausschalten  | Alle vier Potentiometer gleichzeitig deaktivieren                             |
| Alle Potentiometer einschalten  | Alle vier Potentiometer wieder aktivieren, letzten Registerwert wiederherstellen |
| Mittelstellung setzen           | Alle Potentiometer gleichzeitig auf Registerwert 128 (~500 Ω) setzen         |
